# لایسنس آفلاین AsiaFactor

این نسخه شامل چارچوب فعال‌سازی آفلاین یک‌دستگاهی است:

- در اولین اجرا، برنامه صفحه فعال‌سازی را نمایش می‌دهد.
- «ساخت فایل درخواست فعال‌سازی» یک فایل JSON شامل کلید عمومی دستگاه می‌سازد.
- صادرکننده مجوز روی کامپیوتر، فایل درخواست را با کلید خصوصی مالک امضا می‌کند.
- کاربر فایل مجوز را در برنامه وارد می‌کند؛ برنامه امضا و تطابق کلید دستگاه را بدون اینترنت بررسی می‌کند.
- کلید خصوصی دستگاه در Android Keystore نگهداری می‌شود و به‌صورت فایل صادر نمی‌شود.
- فایل مجوز در حافظه داخلی برنامه ذخیره می‌شود. پشتیبان‌گیری اندروید برای این برنامه غیرفعال شده تا فایل مجوز به‌سادگی به دستگاه دیگری بازیابی نشود.

## صدور مجوز

از پوشه جداگانه `AsiaFactor-License-Admin.zip` استفاده کنید. آن بسته حاوی ابزار صدور و کلید خصوصی است و باید محرمانه نگه داشته شود. کلید خصوصی هرگز نباید در APK یا پروژه‌ای که به مشتری می‌دهید قرار بگیرد.

## محدودیت‌ها

- این طرح برای استفاده آفلاین است؛ امکان ابطال از راه دور یا تشخیص هم‌زمانی استفاده وجود ندارد.
- حذف برنامه یا پاک کردن داده‌های آن ممکن است کلید دستگاه را حذف کند؛ در این صورت باید درخواست تازه صادر شود.
- این قفل جلوی انتقال ساده APK و فایل مجوز را می‌گیرد، اما در برابر مهندسی معکوس حرفه‌ای تضمین مطلق ندارد.
- اطلاعات فاکتورها را مستقل از وضعیت مجوز نگه دارید و پیش از انتشار، مسیرهای ذخیره‌سازی/پشتیبان‌گیری را آزمایش کنید.

## وضعیت ساخت

سورس اصلاح شده است، اما در محیط آماده‌سازی فعلی Android SDK موجود نبود و دانلود Gradle نیز به دلیل نبود دسترسی شبکه انجام نشد؛ بنابراین APK ساخته و روی دستگاه آزمایش نشده است. پروژه را در Android Studio باز کنید، Gradle Sync را اجرا کنید و سپس `Build > Build APK(s)` را بزنید. قبل از توزیع، فعال‌سازی، نصب مجدد، واردکردن مجوز اشتباه و تلاش برای استفاده از مجوز در گوشی دوم را آزمایش کنید.
